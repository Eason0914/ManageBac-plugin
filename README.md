# ManageBac Planner（Edge 插件）

自用的 Edge 侧边栏插件：自动同步 ManageBac 作业（iCal），手动添加任务，DeepSeek 估时与每日规划，计时器记录真实耗时，并按科目校准估时。

## 安装

1. 下载本仓库（Code → Download ZIP 并解压，或 `git clone`）。
2. Edge 打开 `edge://extensions`，打开左下角 **开发人员模式**。
3. 点 **加载解压缩的扩展**，选择本仓库文件夹（包含 `manifest.json` 的那一层）。
4. 点工具栏上的插件图标即可打开侧边栏（可以先在扩展菜单里把它"固定"到工具栏）。

更新代码后，在 `edge://extensions` 里点该插件的 **重新加载** 即可，数据不会丢失。

## 首次设置

在侧边栏右上角 ⚙ 打开设置页：

1. **iCal 订阅**：每门课填一个科目名 + 日历链接（`webcal://` 或 `https://`，域名需为 `*.managebac.cn`），点"立即同步"。每行右侧会显示最近同步时间或错误。
2. **DeepSeek API key**：填入后点"测试"。新同步的任务会自动估时。
3. 可调整同步间隔（默认 120 分钟）、计时提醒阈值（默认 180 分钟）、忽略关键词。
4. **备份 / 迁移**：导出 JSON（API key 永不导出；iCal 链接默认不导出，可勾选）。导入为合并模式。

## 使用

- **任务分组**：逾期 / 今天 / 本周（到本周日）/ 以后 / 近 7 天已完成。勾选"显示已忽略 / 已移除 / 记录前"可查看被隐藏的任务。
- **开始记录日期**：在这个日期之前就已截止、且仍未完成的 iCal 作业不算逾期，归入"记录前"（隐藏，不参与估时、规划和统计）。默认是首次使用（或升级到此版本）的那天，可在设置页修改。
- **计时**：任务右侧 ▶ 开始，❚❚ 暂停；同时只会有一个任务在计时，开始新的会自动结束旧的。计时期间工具栏图标显示分钟数角标；单次计时超过阈值会弹系统通知。
- **完成**：勾选复选框。若该任务从未计时，或本次计时超过阈值，会弹窗让你填写/修正实际耗时。
- **⋯ 菜单**：忽略 / 取消忽略、编辑（仅手动任务）、修改耗时。
- **规划今天**：填写今天的可用时段（可多段），DeepSeek 生成时间表并显示在顶部；点击时间块直接开始计时。
- **统计**：今日完成情况与总计时、近 7 天完成数柱状图、各科目校准系数与样本数。

## 实现说明（规格之外/不明确处的处理）

- **存储**：每个任务存为独立的 key `task:<id>`（而不是一个大数组），避免后台同步与面板同时写入时互相覆盖。计划存为 `plan:<日期>`。
- **iCal 时间**：全天事件（`VALUE=DATE`）的截止时间视为当天 23:59（上海时间）；带 `TZID` 的按该时区换算；不带时区的按上海时间处理。
- **移除判定**：只有当某科目的 feed **本次拉取成功**时，才会把该科目下消失的未来任务标为 `removed`（避免断网时误判）；已完成的任务不会被标为 removed。被移除的任务若重新出现在日历中，会自动恢复为 `todo`。
- **科目改名**：在设置页修改科目名时，已有任务的科目会一并更新，以保持校准数据连续。
- **修正耗时**：任务有计时记录时，修正值通过调整最后一段计时的结束时间实现；没有计时记录时写入 `manualMinutes`。
- **今日完成率** = 已完成 ÷（今天截止的任务 ∪ 今日计划中的任务 ∪ 今天完成的任务），不计忽略/移除的任务。
- **AI 估时**只针对 `todo` 状态且未估过的任务（忽略的任务不估）；按科目分批，每批最多 20 条。
- **规划**发送截止时间最近的最多 60 个待办任务；未估时的任务按 30 分钟计。
- `activeTimer` 额外带一个 `warned` 字段，保证每段计时只提醒一次。
